# YABAR: Yet Another Burn After Reading

YABAR is a tiny secret-sharing tool that can run in low-cost cloud tiers.

*   The [Cloudflare implementation](cloudflare/README.md) is currently
    maintained.

*   The [Azure implementation](azure/README.md) is a proof of concept that runs
    at the time of writing but is no longer maintained.
